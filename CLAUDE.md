# Immersive Spellcraft - Forge 1.20.1 Mod

## Orientation
The design brief is `Immersive_Magic_Coding_Agent_Guidance.md` (it calls the mod "Immersive Magic"; every
`immersive_magic` name there is `immersive_spellcraft` here). 0.1.0 = its milestones M0 + M1. Architecture and
decisions: `docs/architecture.md`; config, profiles, commands: `docs/configuration.md`; pinned artifacts and the tested
matrix: `docs/compatibility.md`; per-operation status: `docs/coverage.md` (generated from `docs/coverage.json`).
`MODMAP.md` is generated by `.mcmod-tools/modmap.py`.

## Quick Reference
- **Mod ID**: `immersive_spellcraft`  **Package**: `com.otectus.immersivespellcraft`
- **MC / Forge / Java / integration pins**: see `gradle.properties` (only place versions live)
- **Mappings**: official
- **Protocol versions**: `ModNetwork.VERSION` (packets), `GameTypes.GENERATOR_VERSION` (game generators), each
  adapter's `VERSION`

## Build
- `.mcmod-tools/gradlew-quiet.sh <dir> compileJava` - compile only (default compile pin: Iron's 3.16.3)
- `... test` - JUnit suite (`src/test`, pure simulation)
- `... runGameTestServer [-Pwith=ars,irons,ans|all] [-PironsVersion=315]` - GameTests per run profile; each profile
  has its own `run-gametest/<profile>/` world. `-PcoverageExport=<file>` writes the runtime coverage manifest.
- `... build` - reobfuscated jar in `build/libs/`
- `runClient -PsmokeTest` - client agent (`src/smokeTest`): plays every practice game, screenshots in `run/<profile>/`
- Ars 'n Spells 3.4.0 is read from `libs/ars_n_spells-3.4.0.jar` (slim, compile + dev runtime); copy it from
  `../ars-n-spells/build/libs/` (git-ignored, never shipped)

## Structure
```
minigame/   pure, deterministic, no Minecraft imports: stages, Simulation, GameTypes, ScoreCard, Autoplay. Unit-tested
core/       adapter contract (inspect/begin/validate/commit/interrupt), PreparedOperation, AdapterRegistry, MenuGuard
session/    SessionManager (admission, station lock, one-use commit permit), InputValidator, MenuGuards, events
network/    one version-locked channel; clients send control edges only
data/       operation profiles (strict parser, validated snapshot per reload), coverage catalog and exporter
compat/     bootstrap (by class name after ModList + version check), mixin plugin; ars/ irons/ ans/ adapters
mixin/      core/ (vanilla: clicked guard, packet lock, client intercept, pause) and compat/ (remap=false, both names)
client/     panel, renderers, overlay over station screens, block-station screen, practice, input model
```

## Conventions
- The native station performs the operation, once: never build a result, never charge or refund.
- Server authoritative: clients send bounded control edges, never a score, stack or completion.
- Optional mods only under `compat/<mod>/`, reached by class name; GameTest scenarios that touch them live in
  `*Scenarios`/`*Fixtures` classes called only after the presence check.
- Automation (fake players) is never asked to perform.
- Player-facing text is always a key in `assets/immersive_spellcraft/lang/en_us.json`.
- Any change to a game generator's output: bump `GameTypes.GENERATOR_VERSION`; any wire change: `ModNetwork.VERSION`.
